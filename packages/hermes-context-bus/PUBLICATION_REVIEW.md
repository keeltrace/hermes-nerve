# Publication review

This directory is a sanitized public-review copy of HermesContextBus.

Included by explicit allowlist:
- Hermes plugin runtime
- SQLite/WAL durable store
- optional generic MCP blackboard adapter
- core protocol/library modules
- installer and renderer
- architecture/spec documentation
- tests, including the Nerve compatibility and sanitization contract

Intentionally excluded:
- machine-specific deployment notes
- private repository provenance
- maintainer-only agent instructions
- local MCP launcher configuration
- adapters that only contained private integration TODOs
- generated runtime/state
- VCS metadata

This is a draft review surface. Publication as a standalone repository should additionally receive a license/provenance review before release.
