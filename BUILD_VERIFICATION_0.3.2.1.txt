Runtime boundary
----------------
Hermes' current plugin hook surface does not provide a supported generic hook
for rewriting the already-assembled provider tool-schema array. v0.3.2.1 does
not monkey-patch Hermes. Tool and skill APPLY plans are adapter outputs intended
for Hermes' existing progressive Tool Search / skill-discovery seams. Memory
providers can map structured candidates through the same admission controller.

Default runtime remains conservative:
  memory_mode=shadow
  tools_mode=shadow
  skills_mode=shadow
  semantic_enabled=false
  lease_enabled=true
