# Nerve unbounded-executable command names (policy data, auditable).

# A command on this list is never treated as bounded execution
# (see hermes_nerve.risk._is_unbounded_executable): it reaches the full
# classification path instead of a bounded fast-path. Exact case-sensitive
# name match. One entry per line; blank lines and #-comments are ignored.
# Loaded once at import; a missing, empty, or duplicate-entry table fails
# the import loudly instead of weakening the policy.
#
# 'env' intentionally appears once. The original Python set literal listed
# it twice; frozenset semantics collapse duplicates identically, and this
# table forbids duplicates so the guard stays strict.
